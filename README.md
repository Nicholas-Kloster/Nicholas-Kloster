# Nick Kloster

Security researcher. Infantry veteran. Poet.

I find vulnerabilities in things and tell the people who built them. Self-taught, disclosure-first, eight years Army with two combat deployments. The goal is always to help people.

## What I do

**Security research** — ICS/OT vulnerability analysis, web infrastructure reverse engineering, AI/LLM security. Published [CISA advisory](https://www.cisa.gov/news-events/ics-advisories/icsa-25-140-11) (CVE-2025-4364, CVSS 8.7). Google VRP-confirmed sandbox escape. Responsible disclosures to Amazon, Anthropic, and others.

**Build things** — tools, instruments, education. I don't just find bugs — I ship software.

**Write** — poetry under the name Savio. Security papers. Research that tries to make complicated things legible.
